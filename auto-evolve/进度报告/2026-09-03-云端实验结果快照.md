## SpreadsheetBench 已确认结果

历史结果存在评测运行时变化，不能把不同运行时的分数混为同一矩阵。当前可保留的两组事实为：

- 旧五条件共同口径：MiniMax M2.7 测试时，无 Skill `67/280`，AEV merge-as-old `83/280`，optMiniMax M2.7 Skill `73/280`，AEV merge-as-opt `98/280`，SkillOpt 官方 GPT-5.5 Skill `89/280`。
- 2026-09-02 独立完整重测：MiniMax M2.7 + SkillOpt 官方 GPT-5.5 Skill，官方 test280、原生多轮工具模式、5 并发，hard `85/280 = 30.36%`，soft `36.67%`，280 个唯一 UID，进程退出码为 0。

这两个官方 Skill 数值来自不同运行记录，正式论文使用前必须按模型、provider、evaluator/runtime、工具模式、turn 上限、输出上限和 UID 重新确认是否属于同一 comparison group，不能择高覆盖。

## 当前研究方向

1. 小样本长程 Skill 生成与 held-out 泛化。
2. 单任务基础 Skill 经过验证后再合并，与原始轨迹直接合并的受控比较。
3. 生产者与消费者模型之间的 Skill 效用、增益和回归分析。
4. 较弱生产者能否通过更多验证计算缩小与强生产者的 Skill 质量差距。

详细边界、文献重叠和实验计划见 `论文思路库/论文方向探索树.md`。
