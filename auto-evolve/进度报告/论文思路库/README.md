# Auto-Evolve 论文思路库

这里用于保存彼此独立的论文叙事，而不是把所有实验强行塞进同一篇论文。

## 使用规则

- 每个思路使用一个两位编号目录，例如 `01-...`、`02-...`。
- 每个目录至少包含：`README.md`（核心论点）、`证据与边界.md`（已有数据和不能说的话）、`实验计划.md`（若要投稿仍缺什么）。
- 已完成论文不移动、不覆盖；本目录只保存入口、证据定位和新的写作路线。
- 运行中的实验结果先进入对应思路的证据文件；只有 `172/172` 或明确的共同有效 cohort 且无基础设施污染的结果，才能进入正式主张。
- 禁止写入 API key、Cookie、原始材料、private answers、runtime-state 或完整运行产物。
