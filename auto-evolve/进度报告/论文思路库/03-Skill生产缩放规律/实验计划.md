# 思路三：未来实验设计

## 实验网格

| 轴 | 建议取值 |
|---|---|
| 生产模型 | 至少 3 个能力档位 |
| 经验管线 | 原生 SkillOpt rollout、AEV 验证经验 |
| 计算预算 | `1x / 2x / 4x / 8x` |
| 随机重复 | 每格至少 3 次 |
| 部署测试 | 固定消费者和固定 held-out 测试集 |

## 主指标

- 最终冻结 Skill 的 hard accuracy；
- Skill 相对无 Skill 的配对增益；
- 每个预算下的有效经验包数和验证通过率；
- prompt、completion、cache-read token、调用数、墙钟时间；
- 用低预算拟合点预测高预算表现的误差。

## 预期图表

1. 预算-准确率曲线：原始 token 为横轴。
2. 有效经验-准确率曲线：验证通过的经验包数为横轴。
3. 等效果曲线：不同生产模型达到同一目标准确率所需预算。
4. 预测检验图：拟合曲线对未见预算点的预测与真实值对比。
