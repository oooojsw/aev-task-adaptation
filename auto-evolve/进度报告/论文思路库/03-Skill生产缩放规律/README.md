# 思路三：Skill 生产缩放规律

## 工作标题

**Scaling Laws for Skill Production: Trading Producer Capability for Verified Experience Compute**

中文工作标题：**Skill 生产缩放规律：用验证式经验计算交换生产模型能力**

## 研究问题

最终部署 Skill 的效果，如何随以下三个量共同变化：

1. Skill 生产模型的能力；
2. 用于经验生产的计算预算；
3. 计算是否被用于可验证的长程经验，而非普通重复 rollout。

核心假设不是“token 越多越好”，而是：经过验证的有效经验量比原始 token 数更接近决定最终 Skill 效果的变量。

## 目标规律

要研究两条曲线：

- **经验计算缩放曲线**：同一生产模型在 `1x / 2x / 4x / 8x` 验证式经验预算下，最终 Skill 的效果如何增长和饱和；
- **能力-计算替代曲线**：较弱生产模型需要多少验证式经验计算，才能达到较强生产模型在较低预算下的同等 Skill 效果。

## 当前状态

现有 MiniMax M2.7、AEV 与官方 GPT-5.5 Skill 的对比，只提供一个“可能存在能力补偿”的离散观察。它没有预算曲线、没有预测检验、没有多模型多预算重复，因此不能称为 Scaling Law。

## 与第二篇的边界

- 第二篇只问：验证式经验是否能在固定条件下缩小一次具体的生产者能力差距？
- 第三篇问：这种补偿如何随模型能力和计算预算系统变化，能否拟合和预测？

第三篇必须等第二篇的同预算对照和多次重复产生足够数据后再启动。
