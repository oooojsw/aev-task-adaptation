# 思路三：现有信号与证据门槛

## 现有信号

OfficeQA 中，MiniMax M2.7 原生 SkillOpt 产物、MiniMax M2.7 的 AEV 产物和官方 GPT-5.5 Skill 的部署成绩不同，说明生产者能力与经验生产方式确实可能共同影响最终 Skill。

这只能用来提出假设，不能拟合规律。

## 成为 Scaling Law 论文的最低证据门槛

- 至少三个明确能力档位的生产模型；
- 每个生产模型至少四档几何计算预算，例如 `1x / 2x / 4x / 8x`；
- 普通 rollout 与 AEV 验证经验两条并行曲线；
- 每一个点至少三次独立训练重复；
- 固定数据切分、Skill 初始化、合并器和冻结部署评测；
- 先用低预算点拟合，再预测高预算点，并检验预测误差；
- 同时报原始 token 与验证通过的有效经验包数。

## 禁止的提前结论

- 不把三个离散 Skill 的分数称为“定律”。
- 不把高 token 消耗等同于有效经验计算。
- 不把某个消费者上的追平外推到所有模型和任务。
