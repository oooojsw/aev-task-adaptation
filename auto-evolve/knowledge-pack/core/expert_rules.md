# 核心专家规则

## 任务概述

从中文条件规则文本中提取两个字符并拼接输出。

## 输入格式

- 模式：`如果有X，必然有Y`
- X 和 Y 是单个汉字字符或拉丁字母
- 例如：`如果有a，必然有b` 或 `如果有b，必然有c`

## 核心变换规则

1. 识别输入文本中的"如果有"和"必然有"模式
2. 提取"如果有"之后的第一个字符（或字母）
3. 提取"必然有"之后的第一个字符（或字母）
4. 将两个字符直接拼接得到输出

## 通用输出规则

- 输出必须是纯文本
- 输出只能是拼接后的两个字符
- 禁止输出任何解释、换行或其他字符
- 精确匹配模式（text_exact）：输出内容必须与期望结果完全一致

## 重要约束

- 不得添加任何前缀或后缀文字
- 不得在输出中包含空格或换行
- 不得输出"答案："等引导性文字
- 宁可返回错误结果也不能输出解释性文字（因为解释会破坏精确匹配）
