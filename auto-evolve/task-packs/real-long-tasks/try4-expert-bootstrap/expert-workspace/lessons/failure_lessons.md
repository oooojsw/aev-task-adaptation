## Generalized Learning That Survived Across Rounds

- Chinese text placeholders in OOXML can span multiple <w:r> runs. Simple string replace misses cross-run placeholders. Must use OpenXML DOM traversal or regex across full document content.
- Source.xlsx stores L12=20260 as integer, not string '20,260.00'. Display formatting must be applied during fill, not expected pre-formatted in source.
- Simple Python zipfile text replacement misses Chinese placeholder text that spans multiple XML runs or lives in header/footer parts not processed in main document loop.
- dotnet OpenXML CLI merge-runs is a prerequisite before fill — it consolidates split runs so that the CLI's replace-text can find placeholders that span multiple runs.
