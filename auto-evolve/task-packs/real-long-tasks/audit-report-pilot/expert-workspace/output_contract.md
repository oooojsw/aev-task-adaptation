# Output Contract - Audit Opinion Document Generation

## Purpose
This document defines the output format, quality standards, and structural requirements for audit opinion documents generated from the expert workspace.

## Output Document Type
- **Primary**: 内部审核意见 (Internal Audit Opinion)
- **Supporting**: Audit review working paper

## Quality Standards

### Completeness Checkpoints
1. All six audit dimensions covered:
   - Risk assessment and weight derivation
   - Capital cost uplift calculation
   - Trademark perpetual revenue period determination
   - Foreign revenue growth rate specification
   - WACC cross-table verification
   - Depreciation period cross-check

2. Derivation chain traceability:
   - Cell reference mapping to source Excel
   - Formula verification steps
   - Cross-table reconciliation (勾稽) validation

3. Conclusion alignment with derivation evidence

### Format Requirements
- Structured markdown or document format
- Clear section headers for each audit dimension
- Footnotes citing source derivation paths
- No orphaned conclusions without supporting derivation

### Quality Checklist
- [ ] Cell reference paths verified
- [ ] Formula calculations confirmed
- [ ] Cross-table reconciliation passed
- [ ] Parameter extraction rules applied
- [ ] Inconsistency detection rules executed
