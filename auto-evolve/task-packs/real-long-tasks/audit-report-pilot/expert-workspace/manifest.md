# 资产评估内部审核意见专家知识包

## 1. 知识包目的

本知识包指导空白智能体（blank agent）在无原始底稿的情况下，独立推导出合格的资产评估内部审核意见。知识包存放路径为 expert-workspace/，包含 manifest.md（主规则文件）、change_log.md（迭代追踪）和 surface_contract.json（机器控制契约）。

## 3. 六大审核维度

### 维度一：评估方法选择的合理性

**审核要点：**
- 评估方法是否与评估目的、资产类型、行业特征相匹配
- 收益法、市场法、成本法三种主要方法的选择依据是否充分
- 收益法中折现率的确定依据（无风险利率、风险溢价、β系数）
- 市场法中可比公司的选取标准
- 成本法中重置成本、成新率的计算逻辑

**推导规则：**
- 若采用收益法，需确认：①未来现金流预测年限；②预测增长率是否与历史增长率存在显著背离；③折现率是否高于行业平均水平
- 若采用市场法，需确认：①可比公司数量是否足够（≥3家）；②价值比率选择是否与行业惯例一致
- 若采用成本法，需确认：①是否存在功能性贬值或经济性贬值未扣除；②成新率是否与实际使用状况吻合

**数据定位：**
- 评估方法选择依据 → 评估报告正文「评估方法」章节
- 折现率参数 → 收益法计算表或评估说明中 WACC/DCF 参数表
- 可比公司信息 → 市场法评估章节或可比公司列表文件

### 维度二：关键假设的明确性和依据

**审核要点：**
- 收入预测假设是否基于合理的历史数据趋势
- 毛利率假设是否与行业水平一致
- 增长率假设是否有合同、订单、市场调研支撑
- 营运资金追加率、资本性支出假设是否合理
- 永续增长率的选择依据

**推导规则：**
- 所有关键假设必须可在底稿中找到对应的支持性文件或数据点
- 若假设与行业平均水平差异超过±30%，需在意见中特别说明
- 假设合理性判断基准：与标的公司近3年历史数据对比、与行业公开数据对比、与同类交易案例对比

**数据定位：**
- 收入预测假设 → 收益法计算表「预测利润表」sheet 或评估说明中盈利预测章节
- 毛利率假设 → 收益法计算表「比率分析」sheet 或历史毛利率数据
- 永续增长率 → 收益法计算表「终值」计算 sheet 或评估说明终值假设章节
- 折现率（WACC）→ 收益法计算表「折现率」sheet 或评估说明中参数取值依据章节

### 维度三：重要数据的准确性引用

**审核要点：**
- 财务报表数据的准确性（净资产、净利润、营业收入）
- 市场数据的时效性（评估基准日是否与市场数据日期匹配）
- 折现现金流模型中的每一项输入数据
- 可比公司估值中乘数数据的来源和可靠性

**推导规则：**
- 数据勾稽关系验证：净资产=总资产-总负债；净利润=营业收入-成本-费用
- 数据来源优先级：经审计财务报表 > 未审计但经管理层确认 > 行业数据库
- 对于境外公司或特殊行业，需确认汇率、税率等换算参数的准确性

**数据定位：**
- 净资产、净利润、营业收入 → 评估报告或审计报告中的财务报表
- 评估基准日 → 评估报告封面或委托方信息中标注的基准日
- 折现现金流输入 → 收益法计算表「现金流预测」sheet 各年度数值
- 汇率参数 → 评估说明中汇率取值依据或跨境资产相关章节

### 维度四：风险提示的充分性

**审核要点：**
- 经营风险：依赖主要客户、供应商、技术替代风险
- 财务风险：负债率、流动性、偿债能力
- 市场风险：市场需求变化、竞争加剧、价格波动
- 政策风险：行业监管变化、环保要求、贸易壁垒
- 特殊风险：诉讼、担保、或有负债

**推导规则：**
- 风险提示必须量化：使用概率或金额区间表述，不使用模糊表述
- 主要风险应在前三位的审核意见中明确列示
- 风险与估值结果的敏感性分析是否充分披露

**数据定位：**
- 风险提示章节 → 评估报告「风险分析」或「重大事项说明」章节
- 敏感性分析 → 收益法计算表「敏感性分析」sheet 或评估说明中敏感性分析章节
- 或有负债、担保信息 → 电子底稿「管理类底稿」或评估报告附注

### 维度五：结论的清晰性和逻辑性

**审核要点：**
- 最终评估结论是否明确（数值或区间）
- 结论的推导过程是否在逻辑上自洽
- 不同评估方法的结果是否存在显著差异，若存在差异是否进行了合理性分析
- 结论是否与委托目的相匹配

**推导规则：**
- 单一方法结论：需说明为何其他方法不适用
- 多种方法加权平均：需说明权重确定依据
- 结论区间化：需说明区间宽度是否在合理范围内（通常不超过±15%）

**数据定位：**
- 评估结论数值 → 评估报告封面或正文「评估结论」章节，格式如「人民币XXXX万元」
- 各方法评估值 → 评估报告「评估结果」表格，列示市场法/收益法/成本法各结果
- 差异合理性分析 → 评估报告「评估结论分析」或「各方法比较分析」章节

### 维度六：格式规范性

**审核要点：**
- 标题格式：XX公司XX项目内部审核意见
- 文档结构：背景、审核范围、审核依据、审核发现、结论、签章
- 日期格式：YYYY年MM月DD日
- 签章要求：审核人员签字、项目负责人签字、日期

**推导规则：**
- 格式检查清单：封面标题、正文结构、结论段落、签章栏、页脚页眉
- 规范性引用：是否符合委托方指定的模板格式要求

**文件命名规范：**
- 输出文件格式：.docx
- 命名格式：[委托方名称]股权价值内部审核意见-[状态].docx
- 状态可选：草稿、修订版、终稿

## 4. 执行工作流

### 步骤一：定位材料

1. 确认评估项目名称和报告编号
2. 在 materials/定稿/ 目录下找到对应的评估报告 PDF 和 Excel 计算表
3. 在 materials/电子底稿/ 目录下确认底稿结构

### 步骤二：提取关键参数

1. 从评估报告封面提取：委托方、被评估单位、评估目的、评估基准日、报告编号
2. 从评估报告正文提取：评估方法选择、各方法评估值、关键假设
3. 从收益法计算表提取：预测现金流、折现率、永续增长率、WACC 参数
4. 从土地/无形资产/设备计算表提取：各类资产的重置成本和成新率

### 步骤三：逐维度推导

按维度一至维度六的推导规则，对每项审核要点进行逐一分析，使用数据定位规则从材料中提取证据，形成明确结论。

### 步骤四：撰写审核意见

按照输出格式契约要求撰写 .docx 格式的审核意见，每项发现使用标准模板格式。

### 步骤五：自我检查

- 是否覆盖全部六个审核维度
- 每项发现是否有证据支撑
- 结论表述是否明确，无模糊语言
- 风险提示是否量化
- 文件命名是否符合规范

## 8. 公式验证推导规则（Formula Verification Derivation）

### 8.1 PPI调整公式验证

**用途：** 验证收入预测中的PPI（生产者价格指数）调整是否正确应用

**文件定位：** 收益法计算表中含「PPI」「价格指数」「调整」关键词的工作表

**验证步骤：**
1. 定位PPI调整公式所在单元格
2. 确认基准单价数据来源（通常在「历史数据」或「参数表」sheet）
3. 验证PPI增长率取值：是否来自国家统计局数据、法国INSEE数据、或合同约定
4. 核对计算链条：PPI数据 → 中间计算 → 应用到收入预测
5. 检验公式的时间对齐：预测期PPI对应的是预测年度还是基期年度

**交叉验证点：**
- 调整后单价的变动幅度是否超过合理范围（通常±20%以内）
- PPI增长率是否与宏观经济数据一致

### 8.2 折现率（WACC）公式验证

**公式结构：**
WACC = Ke × E/(D+E) + Kd × (1-T) × D/(D+E)
其中：Ke = Rf + β × (Rm - Rf)

**关键参数提取：**
- Rf（无风险利率）：取自H10单元格，通常为国债收益率
- β（贝塔系数）：取自H83单元格，需与可比公司β对比
- (Rm - Rf)（市场风险溢价）：取自AG9单元格
- D/E（资本结构）：取自财务报表或评估说明

**验证步骤：**
1. 确认WACC计算表的公式结构与上述一致
2. 检查Kd（债务成本）是否已扣除税率影响 (1-T)
3. 核对权重（D/E）与实际资本结构是否匹配
4. 验证最终WACC数值是否在合理区间（根据行业特性）

### 8.3 终值（Terminal Value）公式验证

**公式结构：**
TV = FCFn × (1+g) / (WACC - g)
或
TV = FCFn / (WACC - g)

**验证步骤：**
1. 确认最后一年自由现金流（FCFn）取自「现金流预测」sheet
2. 验证永续增长率（g）取自P65单元格或「终值」sheet
3. 确认g < WACC（数学收敛条件）
4. 检查TV占企业价值比例是否合理（通常不超过60%）

## 9. 交叉表勾稽推导规则（Cross-Table Reconciliation）

### 9.1 折旧/摊销与ADJ表勾稽

**用途：** 验证折旧摊销计算表与调整表（ADJ表）之间的一致性

**文件定位：**
- 折旧摊销计算表：设备计算表、土建计算表、无形资产计算表
- ADJ表：收益法计算表中含「ADJ」「调整」关键词的工作表

**勾稽算法：**

**步骤1：定位折旧/摊销数据**
- 在设备/土建/无形资产计算表中查找折旧金额列
- 记录格式：「年折旧额」「本期折旧」「累计折旧」
- 提取关键值：原值、折旧年限、年折旧额、累计折旧

**步骤2：定位ADJ表对应条目**
- 在收益法计算表的ADJ sheet中查找对应科目
- 确认折旧/摊销调整项的数值

**步骤3：匹配验证**
如果：折旧计算表年折旧额 ≠ ADJ表折旧调整额
则：报告差异，标记为「勾稽不一致」
允许容差：±100元（由于四舍五入或汇率换算造成）

**差异报告模板：**
【勾稽差异】
科目：[折旧/摊销]
计算表数值：[XXX元]
ADJ表数值：[YYY元]
差异：[ZZZ元]
差异率：[差异/计算表数值 × 100%]
原因分析：[需进一步追溯]

### 9.2 设备折旧明细与资产注册表勾稽

**查找规则：**
1. 在电子底稿「3.操作类底稿」中查找设备台账或资产注册表
2. 比对设备计算表中的原值、折旧年限、累计折旧
3. 确认账面价值与实物资产是否一致

**匹配字段：**
- 设备编号
- 设备名称
- 原值
- 折旧年限
- 累计折旧
- 账面净值

### 9.3 无形资产技术资产组比率勾稽

**用途：** 检测无形资产（技术资产组）中技术价值比例的内部一致性

**常见不一致情形：**
- 评估说明中技术资产组比例20%，但计算表中使用40%
- 不同评估公司采用不同技术折现率

**检测规则：**
1. 从评估说明中提取技术资产组的价值占比（如「技术资产组占比20%」）
2. 从无形资产计算表中提取实际使用的技术资产组比例
3. 若两者差异超过5个百分点，标记为「技术比率不一致」
4. 在审核意见中需说明差异原因及影响

**优先级规则：**
- 评估说明优先于计算表（评估说明是最终结论）
- 若评估说明存在矛盾，以主要评估公司结论为准

### 9.4 容差阈值标准

| 勾稽类型 | 容差阈值 | 处理方式 |
|----------|----------|----------|
| 折旧金额勾稽 | ±100元 | 自动通过 |
| 原值勾稽 | ±1,000元 | 需人工确认 |
| 比率差异 | ±5% | 需报告差异 |
| 大额差异（>10万） | 不允许 | 必须追溯 |

## 10. 特定参数提取规则

### 10.1 风险权重（Risk Weight）提取

**用途：** 从折现率推导过程中提取风险权重值

**数据来源：** 「折现率」sheet 或 WACC 计算表

**提取规则：**
1. 定位「风险溢价」「风险权重」「Risk Premium」行
2. 记录数值及对应的单元格地址（如AG9）
3. 验证风险权重是否与行业平均水平一致
4. 提取系统性风险（β）与特异性风险（α）的分解

**标准格式：**
风险权重 = [数值]%
来源单元格 = [单元格地址]
行业基准 = [行业平均值]%
偏差分析 = [偏高/偏低/正常]

### 10.2 资本成本提升（Capital Cost Uplift）提取

**用途：** 提取资本成本提升幅度，单位为基点（basis points）

**数据来源：** 收益法计算表「折现率」sheet

**提取规则：**
1. 定位「资本成本提升」「Uplift」「调整后WACC」行
2. 记录基点数值（1 bp = 0.01%）
3. 确认提升原因：信用风险溢价、特定行业风险溢价等

**基点计算公式：**
资本成本提升（bp）= (WACC调整后 - WACC基准) × 10000

### 10.3 商标永久收入期（Trademark Perpetual Revenue Period）提取

**用途：** 提取商标资产的永久收入期或有限期判断

**数据来源：** 无形资产计算表或评估说明中商标评估章节

**提取规则：**
1. 查找「商标」「Trademark」「永久」「Perpetual」关键词
2. 若为永久期商标：永久收入期 = 无期限，适用永续折现
3. 若为有限期商标：提取合同约定的收益期限
4. 确认商标收益期限与法律有效期是否一致

**判断标准：**
- 有明确授权合同且在有效期内 → 按合同期限
- 无明确期限但有续期记录 → 可考虑永久期
- 无形资产法律保护期10年，续期后最长可至永久

### 10.4 境外收入增长率（Foreign Revenue Growth）提取

**用途：** 提取境外收入增长率，通常取50%作为重要阈值

**数据来源：** 收益法计算表「预测利润表」或评估说明境外收入章节

**提取规则：**
1. 在「预测利润表」sheet中查找「境外」「国外」「Foreign」收入行
2. 记录预测期各年境外收入金额
3. 计算同比增长率
4. 验证是否出现境外收入占比超过50%的情况

**增长率计算公式：**
境外收入增长率 = (本期境外收入 - 上期境外收入) / 上期境外收入 × 100%

**阈值规则：**
- 若境外收入占比 > 50%，需在审核意见中特别说明汇率风险
- 若境外收入增长率显著高于整体收入增长率，需验证增长合理性

### 10.5 参数提取优先级

| 参数类型 | 优先来源 | 备选来源 |
|----------|----------|----------|
| 风险权重 | 收益法计算表折现率sheet | 评估说明章节 |
| 资本成本提升 | WACC计算表 | 评估说明参数表 |
| 商标永久收入期 | 无形资产计算表 | 评估说明无形资产章节 |
| 境外收入增长率 | 收益法计算表预测利润表 | 评估说明境外收入章节 |
| 无风险利率 | 折现率sheet H10 | 国债收益率官网 |
| β系数 | 折现率sheet H83 | 可比公司数据 |

## 11. 不一致性检测规则

### 11.1 技术资产组比率矛盾检测

**常见矛盾情形：**
- 评估说明标注技术资产组价值占比20%，计算表使用40%
- 不同评估公司对同一技术资产组采用不同折现率

**检测算法：**
1. 提取评估说明中的技术资产组占比声明（如20%）
2. 提取计算表中的实际使用比率（如40%）
3. 计算差异率 = |声明值 - 实际值| / 声明值 × 100%
4. 若差异率 > 5%，标记为「技术比率矛盾」，需在审核意见中说明

### 11.2 折旧年限矛盾检测

**检测规则：**
1. 提取资产台账中的折旧年限（如：设备10年、厂房30年）
2. 提取计算表中的折旧年限设定
3. 若两者不一致，标记为「折旧年限矛盾」
4. 优先以评估说明中的设定为准

### 11.3 折现率跨表一致性检测

**检测规则：**
1. 从收益法计算表提取WACC数值（如12%）
2. 从评估说明提取折现率描述（如「折现率12%-15%」）
3. 若计算值超出描述区间，标记为「折现率超出预期范围」
4. 验证WACC计算公式各参数是否与描述一致

### 11.4 收入预测与历史数据背离检测

**背离阈值：**
- 若预测增长率超过历史增长率±30%，标记为「收入预测背离」
- 若预测毛利率显著偏离历史平均水平±10%，标记为「毛利率背离」

**检测步骤：**
1. 提取近3年历史收入增长率
2. 提取预测期收入增长率
3. 计算背离程度
4. 要求审核意见中说明背离原因

### 11.5 主要客户依赖度风险量化

**量化规则：**
1. 从「管理类底稿」或评估说明中提取前5大客户收入占比
2. 若单一客户占比 > 30%，标记为「客户集中度风险」
3. 若前5大客户合计占比 > 70%，标记为「客户高度集中」
4. 审核意见中需量化表达风险金额

## 12. 每维度自检提示（Per-Dimension Self-Check Prompts）

### 维度一自检提示：评估方法选择的合理性

**自检问题：**
- 收益法中折现率的单元格地址是？（P44/H10/H83/AG9任一）
- 折现率参数是否与评估说明中的描述一致？
- 无风险利率的取值依据是什么？
- β系数是否与可比公司数据匹配？

**证据来源定位：**
- 评估方法 → 评估报告正文「评估方法」章节
- 折现率 → 收益法计算表「折现率」sheet P44单元格
- 可比公司β → H83单元格或可比公司数据表

### 维度二自检提示：关键假设的明确性和依据

**自检问题：**
- 收入预测的单元格地址是？（P11/P12/P16）
- 毛利率假设的来源单元格是？
- 永续增长率来自P65单元格还是其他位置？
- 预测增长率与历史增长率的背离是否超过30%？

**证据来源定位：**
- 收入预测 → 「预测利润表」sheet P11/P12单元格
- 毛利率 → 「比率分析」sheet P16单元格
- 永续增长率 → 「终值」sheet P65单元格

### 维度三自检提示：重要数据的准确性引用

**自检问题：**
- 折旧摊销金额的来源表格是哪个？
- 该金额与ADJ表中的数值是否勾稽一致？
- 容差是否在允许范围内（±100元）？
- 固定资产原值与资产注册表是否一致？

**证据来源定位：**
- 折旧摊销 → 设备计算表/无形资产计算表
- ADJ表 → 收益法计算表「ADJ」sheet
- 资产注册表 → 电子底稿「3.操作类底稿」

### 维度四自检提示：风险提示的充分性

**自检问题：**
- 风险权重是否已量化提取（来源：折现率sheet）？
- 客户集中度风险是否已量化（前5大客户占比）？
- 或有负债金额是否已在底稿中核实？
- 敏感性分析数据来自哪个工作表？

**证据来源定位：**
- 风险权重 → 「折现率」sheet AG9单元格附近
- 客户数据 → 「管理类底稿」或评估报告
- 敏感性分析 → 「敏感性分析」sheet

### 维度五自检提示：结论的清晰性和逻辑性

**自检问题：**
- 不同评估方法的结果差异是否在合理范围内（±15%）？
- 终值计算公式中的参数是否与WACC匹配（g < WACC）？
- 评估结论数值是否与报告封面一致？

**证据来源定位：**
- 各方法评估值 → 评估报告「评估结果」表格
- 终值 → 「终值」sheet TV计算单元格
- WACC → P44单元格

### 维度六自检提示：格式规范性

**自检问题：**
- 输出文件是否以.docx格式命名？
- 文件名是否符合「[委托方]股权价值内部审核意见-[状态].docx」格式？
- 审核意见是否包含六个维度的完整结论？
- 日期是否使用「YYYY年MM月DD日」格式？

**证据来源定位：**
- 格式规范 → 本知识包第6维度章节
- 命名规则 → surface_contract.json
