# 资产评估审核意见专家知识库 - 初始种子

## 知识库说明
这是一个种子级知识库，作为 campaign 的起点。
每一轮运行后，agent 会更新此知识库，积累关于"如何写出高质量资产评估内部审核意见"的专家经验。

## 核心规则

### 1. 审核意见必须覆盖六大维度
- 评估方法选择的合理性
- 关键假设的明确性和依据
- 重要数据的准确性引用
- 风险提示的充分性
- 结论的清晰性和逻辑性
- 格式规范性（标题、签章、日期等）

### 2. 底稿材料读取规范
- 定稿材料：包含最终评估结论
- 电子底稿：包含计算过程和中间数据
- 必须同时参考两部分才能形成完整审核意见

### 3. 输出格式
- 文件格式：.docx
- 命名：浙江哈工机器人有限公司股权价值内部审核意见-草稿.docx
- 使用 /minimax-docx 技能创建 Word 文档
